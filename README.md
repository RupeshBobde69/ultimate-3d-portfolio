# Rupesh Bobde — Ultimate 3D Chaos Portfolio

Interactive full-stack developer portfolio with:
- Three.js scroll fly-through + bloom / chromatic aberration
- Draggable 3D project models
- 5 mini-games (Snake, Memory, Particle Annihilator, Reaction Core, Breakout)
- Neon glass UI, custom cursor, glitch effects

## Live

Deployed on Vercel (see repo homepage / Actions after deploy).

## Run locally

```bash
npx serve .
# or
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Stack

HTML · CSS · Vanilla JS · Three.js (CDN)
